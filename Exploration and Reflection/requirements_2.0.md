## 一、核心需求

1. 定位：个人网站，主打**华丽视觉、强自定义、前沿创意**
2. 技术兼容：可混用 Canvas / WebGL / Three.js/ WebGPU 等技术，页面间视觉差异可极大
3. 内容承载：文本、乐谱、音频、视频、3D 艺术文件阅览
4. 成本：优先**免费 / 极低成本**
5. 部署：支持**自费自定义域名**，公网可访问
6. 长期可维护，拒绝被固定模板束缚
7. 风格切换：支持**一键风格切换**，可在视觉、交互逻辑差异极大的多种风格间无缝切换

## 二、关键约束结论

1. **开源博客模板**：通用成品模板不适用；仅可选用无 UI 纯骨架，视觉全部自研
    
2. **Vue3+Vite vs 纯原生**
    
    - Vue 自由度约 95%，**无视觉 / 3D / 前沿技术限制**
    - 仅少量工程化规范约束（DOM 管控、样式作用域、生命周期），可完全规避
    - 优于原生：工程化、易维护、适合多页面迭代
    - 适配风格切换：Vue 的组件化特性可支撑风格隔离，通过全局状态管理实现一键切换
3. **部署方案（免费版）**
    
    - Vercel：首选，单文件 250MB、带宽 100GB，全球 CDN，部署简单，支持自定义域名
    - Cloudflare Pages：备选，带宽宽松、国内访问更好，单文件上限 100MB
    - GitHub Pages：不推荐，资源加载与路由能力不足
    - 适配创意留存：旧内容集中存储时，大文件（如 3D 艺术文件、高清视频）仍通过 Cloudflare R2 外链分流，部署平台仅承载页面逻辑，不突破存储上限
4. **资源承载影响**
    
    - 前端技术完全兼容，可做音视频可视化、3D 模型展示、自定义乐谱渲染
    - 大文件 / 大量资源：用 Cloudflare R2 外链分流，零成本突破平台限制
    - 注意原创内容版权合规
    - 风格切换资源约束：不同风格的静态资源（如主题样式、专属纹理 / 模型）需按需加载，避免一次性加载导致首屏性能劣化；可通过 Vite 按需分包、动态导入实现

## 三、最终技术栈

- 构建：Vite（支持按需分包、动态导入，适配风格切换的资源加载需求）
- 框架：Vue3（组件化支撑风格隔离、全局状态管理实现一键风格切换；路由配置支撑旧内容专属板块的页面路由）
- 状态管理：Pinia（全局管理风格状态，实现一键风格切换的状态同步）
- 样式：Tailwind CSS + 原生 CSS，动效使用 GSAP
    
    - 风格切换适配：Tailwind CSS 支持自定义主题变量，可通过切换全局变量实现基础风格切换；原生 CSS 用于编写风格专属的复杂样式 / 动画，通过 CSS Modules 或 scoped 样式隔离不同风格
    
- 创意技术：Canvas / WebGL / Three.js/ WebGPU 自由混用
- 部署：Vercel，大资源（含旧内容的大文件、不同风格的专属资源）分流至 Cloudflare R2
- 域名：自行购买，绑定部署平台，HTTPS 自动配置
