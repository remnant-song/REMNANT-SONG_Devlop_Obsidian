一、项目概述
1. 该网站为个人网站，核心定位是华丽视觉、强自定义、前沿创意、个人资产分享。
2. 网站需体现强烈的个性化风格，不依赖通用模板，所有视觉与交互均可自由设计。
3. 内容呈现形式丰富，支持传统Markdown图文的同时支持多种媒体类型。

二、功能需求

1. 页面结构
1.1 首页
- 承载最具视觉冲击力的创意入口，可以包含 3D 场景、动态效果或特殊交互。
- 经过动效或交互后进入导航入口。
1.2 关于我
- 个人详细介绍，可包含经历、技能、兴趣、理念等。
- 支持图文混排，允许嵌入个性化视觉元素。
1.3 作品集与项目展示
- 以列表或网格等形式展示作品项目。
- 每个作品可包含标题、描述、封面图、标签分类。
- 作品详情页支持丰富的媒体内容：图片、视频、音频、3D 模型、乐谱等。
- 支持作品分类与筛选。
1.4 博客或文章
- 支持发表长文、随笔、技术文章等。
- 文章内容可包含代码块、图片、音视频嵌入、乐谱内联等。
- 支持文章标签、归档、搜索。
1.5 联系与社交
- 提供联系表单，访客可直接发送消息，消息能到达网站所有者。
- 展示社交媒体链接，如 GitHub、Twitter、Bilibili 等。
- 可包含电子邮件、即时通讯等联系方式。
1.6 特殊内容专区
- 可以设立独立板块展示特定兴趣内容，如音乐创作、艺术实验、3D 画廊等。
- 板块内页面可拥有与主站风格一致或独立的视觉表现。
1.7 其他自定义页面
- 网站应允许自由创建新页面，不限定数量和结构。

1. 内容类型支持
- 支持富文本排版，包括标题、段落、列表、引用、链接、图片混排。可以直接将github中的笔记仓库进行同步。
1. 创意视觉与交互
4.1 高质量动画与动效
- 页面过渡、元素进出场、滚动视差、鼠标跟随等交互需要丰富的动画效果。
4.5 整体设计具备强视觉冲击力，鼓励实验性、艺术性表达。

5. 用户交互
5.1 响应式设计
- 网站需在桌面端、平板、手机等不同屏幕尺寸下均保持良好体验，风格切换后各端依然适配。初期阶段仅完成桌面端开发适配。
5.2 导航
- 没有导航栏，开屏动画结束后即进入真正的首页，入口均在首页呈现。

6. 内容管理
6.1 内容更新
- Markdown直接同步github的仓库中的Markdown文件。
6.2 格式支持
- 文章与页面内容可使用 Markdown 或类似纯文本标记语言撰写。
- 允许在 Markdown 中嵌入多媒体和特殊组件。
6.3 维护简单
- 不需搭建传统数据库后台，通过Git +github工作流管理内容。

最终技术栈

- 构建：Vite
- 框架：Vue3
- 状态管理：Pinia
- 样式：Tailwind CSS + 原生 CSS，动效使用 GSAP
- 创意技术：Canvas / WebGL / Three.js/ WebGPU 自由混用
- 部署：Vercel，大资源（含旧内容的大文件、不同风格的专属资源）分流至 Cloudflare R2
- 域名：自行购买，绑定部署平台，HTTPS 自动配置
