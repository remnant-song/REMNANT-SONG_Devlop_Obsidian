### 1. 项目概述
构建一个极具视觉冲击力的个人网站首屏（Hero Section），背景为色彩华丽、运动无规律的“粘稠液体海洋”，并具备丰富的用户交互。整体风格前卫、艺术化，能瞬间抓住访客注意力，同时清晰展示个人身份与核心导航。项目基于 **Vite + Vue 3 + TypeScript** 技术栈，便于后续页面扩展。

### 3. 背景效果：粘稠液体海洋

#### 3.1 视觉描述
- **形态**：一片占满屏幕的、缓慢流动的液体表面，类似浓稠的油彩、熔岩灯内部液体或流动的丙烯颜料。
- **色彩**：使用高饱和度、霓虹感的渐变色调，除了黑色，其他颜色均有出现，在液体运动中相互混合、流动。色彩映射由多层噪声驱动，形成无规律且华丽的波浪。
- **质感**：
  - 有类似金属或油膜的光泽感，表面带有 Blinn-Phong 或各向异性高光。
  - 液体厚度感通过着色器中的法线扰动和菲涅尔效应模拟，边缘稍亮。
  - 可选细节：悬浮的微小发光粒子（微生物/气泡），随液体流动漂移、碰撞、消逝。
- **运动规律**：
  - **无规律性**：流体速度场由多层 3D/4D 单形噪声（Simplex Noise）叠加驱动，每层速度、振幅、频率不同，避免周期重复感。
  - **粘稠感**：整体流动缓慢，加速度小，带有惯性感。旋涡和拉丝效果明显，犹如高粘度流体被缓慢搅动。
  - 运动覆盖整个视口，镜头俯视液体表面（正交或弱透视），液体从屏幕各方向持续向中心或随机方向流动，但不产生明显边界。

#### 3.2 技术实现建议（仅供参考，你可以应用更好的实现思路）
- 使用 `THREE.ShaderMaterial` 绘制全屏四边形。
- 着色器核心：
  - 用多层 3D 单形噪声（可引入 `psrdnoise` 或自行实现）计算当前像素的速度矢量，再以此扰动 UV 坐标去采样颜色场。
  - 颜色场为一个大型的 2D/3D 噪声纹理，或者直接在着色器中通过对扰动后 UV 进行多色渐变映射（如 `mix` 多个颜色阶段）。
  - 表面法线由噪声高度场差分计算，配合动态光源方向进行光照。
  - 时间均匀流逝，但速度乘上低频噪声，使不同区域流速有差异，强化“粘稠不均匀”感。
- 粒子系统（可选）：
  - 使用 `THREE.Points` 管理 500–2000 个发光点。
  - 粒子位置跟随流体速度场运动，使用同一个噪声函数查询速度。
  - 粒子大小使用 `gl_PointSize` 随深度或速度变化，并应用圆形精灵纹理或着色器绘制柔光。
  - 粒子颜色从背景色调中吸取，带有半透明叠加，产生“浮游生物”效果。
- 性能考虑：
  - 噪声计算可能较重，需控制噪声层数（建议 3–4 层）。
  - 使用 `requestAnimationFrame`，`uniform` 传递时间，帧率目标 60fps，但需在移动端稳定 ≥30fps。可依据设备像素比降级分辨率或噪声复杂度。

### 4. 交互设计

#### 4.1 鼠标交互（桌面端）
- **光标涟漪**：鼠标在液体上移动时，会产生一圈柔和的色彩涟漪或局部亮度提升，类似手指轻触液体表面引起的波纹。涟漪半径 80–120px，强度随鼠标速度变化（快速移动产生更大变形）。
- **吸引/排斥**：鼠标周围一定半径内（约 150px）的液体缓慢向光标位置汇聚或远离，模拟磁力搅动效果。具体行为：光标下方的速度场叠加一个指向光标的吸引力分量，强度由距离衰减函数控制。
- **拖拽搅动**：按住并拖拽鼠标，在移动轨迹上持续生成一连串小漩涡，液体沿拖动方向被推开，产生明显的粘稠拉丝效果。松手后，搅动效果逐渐被粘性阻尼衰减，约 3 秒恢复自然状态。
- **鼠标静止**：无鼠标事件 5 秒后，液体运动回归全自动无规律漂流，直到再次触发交互。

#### 4.2 触摸交互（移动端）
- 单指滑动 → 等同于鼠标移动产生吸引效果。
- 单指点按 → 等同于点击爆发。
- 双指缩放/旋转 → 可选高级效果：缩放时液体密度视觉变化，旋转时整体涡流方向跟随。
- 需处理 `touchstart/touchmove/touchend`，并防止页面滚动冲突（在首屏区域阻止默认滚动行为，或使用 `passive: false`）。

#### 4.3 交互状态共享
- 所有交互输入（鼠标位置、速度、点按力度等）通过 uniform 传入着色器，或更新一个全局的交互纹理（如 256x256 的低分辨率纹理，存储各个位置的搅动力矢量），由 Shader 统一读取。方案推荐：
  - **方案A（Uniform）**：对于单个光标，直接将鼠标位置、点击状态、衰减半径等通过 uniform 传递，GPU 端计算叠加。
  - **方案B（交互纹理）**：如需支持多点触摸或拖拽轨迹，使用离屏 Canvas 绘制力场纹理，每帧上传到纹理 uniform，Shader 采样该纹理获取扰动向量。本项目建议至少支持单点鼠标轨迹，因此方案A+存储轨迹列表更适合。

### 5. 首屏内容布局

#### 5.1 叠层结构（由底到顶）
1. **WebGL 背景层**：占据整个 viewport 的 Canvas，作为背景不断渲染液体海洋。
2. **半透明遮罩层**（可选）：如果背景过于鲜艳影响文字阅读，可在中央区域叠加一层径向渐变暗色遮罩（`background: radial-gradient(ellipse at center, rgba(0,0,0,0.3) 0%, transparent 70%)`），该遮罩不响应交互。
3. **内容层**：Vue 组件，包含个人信息、导航等，置于顶层，使用绝对定位或 Flex/Grid 居中。

#### 5.2 内容组件
- **头像/Logo**（可选）：圆形或艺术化 SVG 图标，尺寸 80–120px，带有荧光边框或呼吸发光动画。
- **姓名**：大号标题，字体 `72px`（移动端 `36px`）粗体，白色或渐变文字。可使用 CSS `background-clip: text` 配合动态渐变，颜色缓慢变化以呼应背景色调。
- **头衔/简介**：副标题，如“Full-Stack Developer & Creative Coder”，字号 `24px`，浅灰色，轻字重。
- **行动按钮**：1–2 个圆角按钮，如“查看作品 / 联系我”。采用玻璃拟态风格（半透明背景、backdrop-filter: blur(10px)、细白边框），hover 时背景色变亮、轻微放大。
- **向下滚动指示器**：底部居中的动态箭头或“Scroll”文字，带上下浮动动画，提示用户首屏下方有内容。点击后平滑滚动至下一区块。

#### 5.3 响应式与可访问性
- 视口 100vw × 100vh，内容居中，使用 `v-bind` 动态调整字号。
- 背景 Canvas 自适应窗口大小，监听 `resize` 事件更新相机/渲染尺寸，注意设备像素比（`Math.min(window.devicePixelRatio, 2)` 以节省性能）。
- 文字对比度确保 WCAG AA 级，通过遮罩或描边保证在复杂背景上可读。

### 6. 性能与优化要求
- **资源加载**：首屏禁止使用大体积图片/视频纹理，Shader 通过代码生成所有视觉元素。
- **GPU 性能**：着色器复杂度需在主流移动设备（如 iPhone 12）上达到 30fps 以上。可使用 `requestAnimationFrame` 内限制帧率逻辑，或动态降低分辨率（渲染到 0.75 倍缩放 Canvas）。
- **内存管理**：页面切后台时暂停动画循环（使用 `Page Visibility API`），卸载时清理 Three.js 渲染器、几何体和材质，防止内存泄漏。
- **包体积**：按需引入 Three.js 模块，避免全量导入。最终首屏 JS 大小（gzip）目标 <200KB。

### 8. 验收标准
1. 背景呈现无规整重复的粘稠液体海洋效果，色彩鲜艳且持续变化。
2. 鼠标移动时液体产生跟随扰动，点击产生彩色冲击波，拖拽形成拉丝搅动，松手后逐渐复原。
3. 移动端触摸交互正常，性能流畅。
4. 首屏文字清晰可读，按钮具备 hover 动效和点击反馈。
5. 页面大小自适应，在不同分辨率、DPR 设备上表现一致。
6. 浏览器兼容性：Chrome 90+、Firefox 90+、Safari 15+、Edge 90+。
7. 代码使用 TypeScript，类型定义完整，无 `any` 滥用。

### 9. 额外创意选项（非必选，可作为进阶）
- **音频响应**：若用户已播放背景音乐，可将音频频谱数据传入 Shader，使液体颜色或波动强度随节拍跳动。
- **昼夜切换**：根据系统时间或用户点击，切换整体色调（暖色/冷色）。
- **键盘交互**：按下特定按键（如 W/A/S/D）可在流体中生成方向性推力，形成趣味彩蛋。
