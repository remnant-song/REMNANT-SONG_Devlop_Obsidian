## 一、项目基础信息

- 项目名称：REMNANT SONG 个人网站首屏
- 技术栈：Vite + Vue3 + TypeScript
- 核心定位：纯视觉导向的个人站点迎宾首屏，以极致视觉冲击力与独特风格记忆点为第一目标，弱化信息承载，通过氛围感与丝滑动效建立个人品牌视觉印象。
- 风格溯源：从参考二次元视觉图中提取**暗调魔法霓虹**的核心气质，完全去除具象二次元人物形象，将二次元美学转化为抽象的色彩、光影、纹理语言，打造脱离商业化通用范式、风格化极强的个人站点视觉。

## 二、核心设计原则

1. **视觉优先**：所有设计决策以视觉冲击力为第一标准，信息功能让位于氛围表达。
2. **去具象二次元**：不使用任何动漫人物、卡通形象等直白二次元元素，通过色彩、光影、纹理间接传递幻想感与二次元美学内核。
3. **标新立异**：摒弃主流网站居中排版、导航栏置顶、信息密集的商业化设计逻辑，采用非对称布局、极简信息、重氛围的设计思路。
4. **动效为魂**：首屏动效是核心体验之一，追求丝滑、华丽、有呼吸感的动态效果，所有过渡与交互动效做到细腻无卡顿。

## 三、视觉风格详细规范

### 3.1 色彩体系

整体为冷调暗色系，以深邃暗蓝为基底，电光蓝为核心发光色，薰衣草紫为点缀色，构建神秘华丽的暗夜幻想氛围。

- 背景主色：深邃藏青蓝（参考色值 `#0a1028`），带极细微的颗粒噪点质感，四周向中心做微弱的径向提亮，形成暗角聚光效果，避免平面感。
- 主发光色：高饱和冰霓虹蓝（参考色值 `#4dabff`），用于核心纹理发光、交互态高亮，自带柔和的外发光模糊效果。
- 辅助点缀色：低饱和薰衣草紫（参考色值 `#9d8cff`），用于边框描边、文字高光、细节装饰，提升画面层次。
- 文字色阶：
    
    - 主标题：带紫调的亮白色（参考色值 `#e8eeff`），附加微弱蓝紫光晕
    - 次级文字：低饱和灰蓝色（参考色值 `#8a99c2`），低对比度融入背景
    
- 色彩禁忌：禁止大面积高饱和暖色、纯黑纯白，严格维持冷调暗系的统一氛围。

### 3.2 背景与纹理系统

背景采用多层叠加结构，由深到浅营造纵深感，所有二次元相关元素均做抽象几何化处理。

1. 底层：带噪点的暗蓝径向渐变背景，奠定整体暗调基调。
2. 中层：抽象化魔法几何纹理，提取参考图中魔法阵的环形符文、对称几何、星芒碎片特征，做简化、淡化处理，以低透明度线稿形式错落分布在背景中。纹理不作为清晰主体，仅作为氛围感肌理存在，避免具象魔法阵带来的强二次元感。
3. 漂浮层：细碎的淡蓝 / 淡紫色光点与薄片状碎屑，缓慢漂浮下落，对应参考图的花瓣元素，数量克制，点缀画面灵动性，不干扰主体。

### 3.3 排版与文字设计

采用非对称左对齐布局，打破常规居中范式，打造独特视觉节奏。

- 布局结构：所有文字与交互元素集中在屏幕左侧 1/3 区域，垂直居中排布；右侧 2/3 区域留给背景视觉元素，形成左重右轻的非对称平衡，留白充足，呼吸感强。
- 主标题：`REMNANT SONG`，选用带有优雅衬线的标题字体（或设计感无衬线字体），大字号、宽字距，字重偏高，是首屏唯一的视觉核心文字，自带柔和外发光。
- 次级内容：仅保留最多一行短句副标（可选，如 _Echoes of the Unseen_）与一个入口按钮，字号与字重远小于主标题，形成强烈层级差。
- 装饰细节：屏幕边缘添加极细的紫蓝渐变描边，角落可搭配小型抽象几何徽章装饰，呼应参考图的边框与徽章设计，但完全抽象化，无具体标识。
- 排版禁忌：禁止顶部导航栏、多段落介绍、多按钮入口等密集信息元素，严格控制首屏信息数量。

### 3.4 UI 交互元素风格

- 入口按钮：采用透明底色 + 细描边样式，默认状态为淡紫色描边，hover 时平滑过渡为电光蓝并触发外发光效果，按钮文字简洁（如 `Enter`）。
- 所有交互元素均遵循「细线条、发光反馈、无填充」的设计语言，与整体暗调发光风格统一。

## 四、动效设计规范

动效是首屏核心体验，整体节奏缓慢优雅，缓动平滑，无生硬跳转。

### 4.1 入场加载动效

- 页面初始化从纯黑渐变为暗蓝底色，随后背景纹理从中心向外扩散式浮现，亮度逐步提升至稳定状态。
- 主标题文字按字符 / 单词依次渐显，伴随轻微向上位移与光晕从无到有的过渡，各字符入场带有错落时间差。
- 按钮与次级文字最后淡入，整体入场序列形成由背景到前景、由大到小的流畅节奏。

### 4.2 常态待机动效

- 背景纹理呼吸：几何纹理持续进行缓慢的亮度呼吸循环，同时整体做极缓慢的旋转 / 平移漂移，营造 “持续运转” 的静谧魔法感。
- 粒子漂浮：光点与碎屑持续随机缓慢飘落，速度、方向均有随机差异，自然无重复感。
- 文字光晕呼吸：主标题的外发光亮度在小范围内周期性缓慢变化，颜色在蓝紫之间微妙过渡，维持画面灵动性。
- 鼠标引力交互：鼠标移动时，背景纹理的发光亮度会随鼠标位置产生微弱的引力偏移，靠近鼠标的区域微微提亮，形成沉浸式交互反馈。

### 4.3 交互动效

- 按钮 hover：描边颜色从紫色平滑过渡为霓虹蓝，外发光范围与亮度逐渐增强，文字同步提亮，过渡时长 0.3s，缓动平滑。
- 点击跳转：触发中心向外的光效扩散 / 收缩过渡，画面伴随魔法纹理的收束效果平滑淡出，进入站点内页，转场过程流畅无割裂。

## 五、前端实现提示

- 技术栈：基于 Vite + Vue3 + TypeScript 开发，样式推荐使用 SCSS 进行变量管理，复杂序列动效接入 GSAP 实现，粒子与背景纹理可结合 CSS 与轻量 Canvas 实现。
- 性能要求：优先保证首屏视觉加载速度，背景纹理使用 SVG 或压缩位图，动效稳定维持 60fps；做好响应式适配，移动端保留核心视觉氛围与布局逻辑，调整字号与元素占比。
- 开发优先级：色彩氛围还原 > 背景分层与动效 > 文字排版与入场动效 > 交互反馈动效。
