
### 整体世界观：一间动漫风格的“我的房间”

最自然的场景是一个**个人房间（部屋）**，这是动漫中极其常见的、能容纳各种物品的舞台。每个平台都化作房间里的一件物品，等待被探索。

- **整体色调**：柔和暖色或黄昏/夜晚氛围，便于让发光、粒子等华丽效果突出。
- **画面构成**：前景（桌子/地板）、中景（主角物品）、远景（窗户/天空/书架）。这是实现视差的基础。

### 华丽感的来源：不靠3D，靠“动态细节”与“氛围”

华丽不必是模型复杂，而是**光影、层次和微小动画**的叠加。

1.  **多层视差（CSS only 实现）**
    - 将场景拆成 3~5 层（背景天空/窗户、远景书架、中景物与角色、近景桌子、前景装饰物如飘过的窗帘）。
    - 通过鼠标移动（或陀螺仪）让各层以不同速率平移，产生强烈的空间纵深感。实现路径：给一个父容器绑定 `mousemove`，修改各层的 `transform: translate()` 值，比例不同。或使用纯 CSS 的 `perspective` + 子元素的 `translateZ` 配合鼠标坐标变化。

2.  **粒子与光效**
    - **魔法尘埃**：场景中漂浮着数十个微小的发光点（萤火虫/灵力光点），缓慢随机游走。使用纯 CSS 动画多个绝对定位的小圆点即可，设置不同 `animation-delay` 和路径。
    - **体积光**：从窗户射入一道半透明的光束（使用 `linear-gradient` + `opacity` 的平行四边形），缓慢移动角度。
    - **物体高光**：每个物件在 hover 时，会有一道漫画式的“十字闪光”或边缘高光划过。可以用一个倾斜的白色渐变 div，通过 `clip-path` 或 `overflow:hidden` 扫过。

3.  **漫画式点缀**
    - 场景角落可以漂浮着一些 **Q 版表情符号或漫符**（💬、✨、💤），轻微抖动。
    - 电视或电脑屏幕可以显示手绘风格的“正在播放…”文字。

4.  **整体滤镜**
    - 覆盖一层极轻微的**纸质纹理**或**噪点**（使用重复的 SVG 或 CSS `background-image`），让整个场景有“赛璐璐”质感。
    - 色彩使用略微过饱和、带阴影边缘的风格，模拟动画上色。

### 简单的实现路径（Vue 组件化思维）

核心思路是：**用一张绘制的场景图做底 + CSS 驱动的动态物件**，而不是去写复杂的 Canvas 或 WebGL。

#### 技术栈：Vue 3 + 纯 CSS 动画 + 少量 JS 用于视差
- **场景组件 `<AnimeRoom />`** ：负责鼠标追踪、视差比例计算，提供上下文。
- **物件组件 `<RoomItem />`** ：每个平台映射的物件。接收 `posX, posY, depth, link, iconSrc` 等 props。它管理自己的 hover 动画和跳转逻辑。
- **粒子组件**：一个独立的 `<ParticleField />` 作为背景装饰，不参与交互。

#### 实现步骤构思

1.  **绘制/获取素材**
    - 请画师（或AI生成）一张**无物件的空房间背景**（远景+中景桌子/窗户等），然后再为每个物件绘制**单独的透明PNG素材**，最好包含其“正常态”和“高亮态”（或通过 CSS 滤镜变化实现高亮）。
    - 将素材分为 `bg`（远景）、`mid`（桌柜）、`front`（前景）三层图片。

2.  **构建静态布局**
    - 使用绝对定位将各层背景图片放入。
    - 物件组件置于“中景”层上方，用百分比定位，使它们看起来在桌面上、挂在墙上等。

3.  **加入视差**
    - 监听父容器 `mousemove`，计算鼠标相对容器中心的偏移。
    - 根据每个物件/层的 `depth` 属性，计算 `translateX` 和 `translateY` 的偏移量（`depth` 越大，移动越多），更新 CSS 变量或直接修改 `transform`。使用 `requestAnimationFrame` 节流，流畅不卡。

4.  **赋予物件生命力**
    - **待机动画**：每个物件都有一个轻微的浮动或摇摆（如 `@keyframes float`），周期 3~6 秒，各物件错开延迟。
    - **Hover 强化**：鼠标悬停时，物件放大至 110%，点亮边缘光（`drop-shadow` 或发光层），播放特定动画（小猫睁眼、信封旋转等），并显示一个精致的漫画对话框，里面写着平台名。
    - **点击**：触发 `window.open(link)`。

5.  **华丽度升级**
    - 粒子层使用多个绝对定位的 `<div>`，搭配 `border-radius: 50%` 和 `box-shadow` 发光，动画路径用 `transform: translateX/Y` 搭配正弦曲线。
    - 加上一道“窗户体积光”，用 `clip-path: polygon(...)` 并缓慢改变透明度。
    - 添加一个无声的背景音乐控制键？（可选）

### 备选场景：更具想象力的延伸

如果房间场景太普通，也可以考虑：

- **夜空下的天台**：B站是投影在墙壁上的荧幕，GitHub是蹲在栏杆上的猫，邮箱是信号塔，社媒化作星座……
- **魔法书桌**：所有物件悬浮在一个魔法阵上，书本翻开就是 LinkedIn，魔杖是社交开关。
- **赛博街道**：B站是广告牌，GitHub是街角的黑客终端，小鸟是无人机。

但房间场景最亲切、物件映射最自然，也最容易实现华丽视差。

---

这个方案的核心在于**将交互完全融入环境**，让访客产生“翻看你的房间”的探索欲。你可以在进入页面的前几秒，让物件逐个从边缘滑入或从地面弹起，完成一个戏剧性的登场。
