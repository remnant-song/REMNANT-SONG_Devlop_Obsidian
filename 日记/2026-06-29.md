## 设计说明

1. **主色使用 HSL 格式**：组件中的 `color()` 函数会解析 HSL 值并进行亮度调整（`lightAdd` 参数），所以主色变量必须使用 `H S% L%` 格式。

2. **阴影色使用十六进制**：阴影色在组件中直接作为 `stroke` 值使用，不需要亮度计算，因此保持十六进制格式。

## 错误分析与修复

### 错误1：第73行 `{{ item.char }}` — 未解析的变量 char

**原因**：`titleLetters` 是 computed 属性，返回的对象类型未明确声明，IDE 无法正确推断 `item.char` 的类型。

**修复**：添加 TypeScript 接口定义：
```typescript
interface TitleLetter {
  char: string
  x: number
  gradient: string
  shadow: string
}
const titleLetters = computed<TitleLetter[]>(() => { ... })
```

### 错误2：第217行 `var(--index)` — 无法解析自定义属性

**原因**：CSS 变量 `--index` 是通过 Vue 的 `:style` 动态设置的（第72行），IDE 的 CSS 检查器在静态分析时无法识别运行时动态设置的变量。

**修复**：为 CSS 变量添加默认值：
```css
animation-delay: calc(var(--index, 0) * 0.2s);
```

这样即使 `--index` 未定义，也会使用默认值 `0`，不会导致动画延迟失效。
