## 规划：分 4 步

### 第一步：你需要的操作 — GitHub Token（可选但推荐）

| 场景 | 限速 | 是否需要 Token |
|---|---|---|
| 偶尔开发调试 | 60 次/小时（够用） | 不需要 |
| 频繁刷新/生产环境 | 5000 次/小时 | 需要 |

**如果需要 Token**，创建步骤：
1. 打开 [GitHub Settings > Developer settings > Personal access tokens > Tokens (classic)](https://github.com/settings/tokens)
2. 点击 "Generate new token (classic)"
3. 勾选 `repo` 作用域（或 Fine-grained token 选 `Contents: Read-only`，限定到该仓库）
4. 生成后复制 token
5. 在项目根目录创建 `.env` 文件，写入 `VITE_GITHUB_TOKEN=ghp_xxxxxxxxxxxx`

> 不需要的话告诉我，我用无认证模式（60 次/小时足够开发调试）。

### 第二步：架构设计 — 新建 `github-loader.ts`

**核心思路：** 新建一个 GitHub 加载器，与现有 `loader.ts`（本地文件）**接口兼容**，通过配置切换。

```
src/utils/markdown/
├── loader.ts          ← 保留（本地 import.meta.glob）
├── github-loader.ts   ← 新建（GitHub API 拉取）
├── types.ts           ← 新建（共享类型 PostEntry 等）
└── parser.ts          ← 不变（渲染引擎）
```

**`github-loader.ts` 工作流：**

```
1. GET /repos/{owner}/{repo}/git/trees/main?recursive=1
   → 获取完整文件树（1 次 API 调用）

2. 过滤规则：
   ├── 排除 .obsidian/、.gitmodules、resources/
   ├── 排除 git submodule（type === "commit"）
   ├── 仅保留 .md 文件
   └── 排除根目录下的 .md（可选，看你要不要）

3. 分类映射：
   ├── 一级目录名 → category（如 dream、日记、Memoria）
   ├── 嵌套子目录 → category 用 "/" 连接（如 "Exploration and Reflection/Markdown 博客开发规划"）
   └── 文件名去掉 .md → slug

4. 对每个 .md 文件：
   GET raw.githubusercontent.com/{owner}/{repo}/main/{path}
   → 获取原始内容（不限速，不消耗 API 配额）

5. 组合返回 PostEntry[]（与 loader.ts 完全兼容）
```

**API 调用分析：**
- 1 次 API 调用获取文件树（消耗 1 次限速配额）
- N 次 raw 文件下载（不限速，CDN 加速）
- 总计：每次页面加载约 1 次 API 调用 + N 次 raw 下载

### 第三步：路由/组件适配

| 改动点 | 说明 |
|---|---|
| `BlogListView.vue` | 根据环境变量选择 `loadAllPosts`（本地）或 `loadAllPostsFromGitHub`（远程） |

**切换方式**（推荐）：
```ts
// .env
VITE_POST_SOURCE=github  // 或 local

// 在组件中
const loader = import.meta.env.VITE_POST_SOURCE === 'github'
  ? await import('@/utils/markdown/github-loader')
  : await import('@/utils/markdown/loader')
```
