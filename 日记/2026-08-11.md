### 第二步：架构设计 — 新建 `github-loader.ts`

**核心思路：** 新建一个 GitHub 加载器，与现有 `loader.ts`（本地文件）**接口兼容**，通过配置切换。

```
src/utils/markdown/
├── loader.ts          ← 保留（本地 import.meta.glob）
├── github-loader.ts   ← 新建（GitHub API 拉取）
├── types.ts           ← 新建（共享类型 PostEntry 等）
└── parser.ts          ← 不变（渲染引擎）
```

**`github-loader.ts` 工作流：**

```
1. GET /repos/{owner}/{repo}/git/trees/main?recursive=1
   → 获取完整文件树（1 次 API 调用）

2. 过滤规则：
   ├── 排除 .obsidian/、.gitmodules、resources/
   ├── 排除 git submodule（type === "commit"）
   ├── 仅保留 .md 文件
   └── 排除根目录下的 .md（可选，看你要不要）

3. 分类映射：
   ├── 一级目录名 → category（如 dream、日记、Memoria）
   ├── 嵌套子目录 → category 用 "/" 连接（如 "Exploration and Reflection/Markdown 博客开发规划"）
   └── 文件名去掉 .md → slug

4. 对每个 .md 文件：
   GET raw.githubusercontent.com/{owner}/{repo}/main/{path}
   → 获取原始内容（不限速，不消耗 API 配额）

5. 组合返回 PostEntry[]（与 loader.ts 完全兼容）
```

**API 调用分析：**
- 1 次 API 调用获取文件树（消耗 1 次限速配额）
- N 次 raw 文件下载（不限速，CDN 加速）
- 总计：每次页面加载约 1 次 API 调用 + N 次 raw 下载

## 修复完成

**根因：** 路由 `/blog/:category/:slug` 只匹配恰好 2 段路径。嵌套分类 URL 如 `/blog/Exploration and Reflection/首屏/前端3d技术讨论`（3 段）不匹配任何路由，Vue Router 静默失败，组件不挂载，控制台零输出。

**修复：** 两条具体路由合并为一条 catch-all：

| 改前 | 改后 |
|---|---|
| `/blog/:slug` | `/blog/:pathMatch(.*)*` |
| `/blog/:category/:slug` | （合并为上面一条） |

`BlogPostView` 中解析逻辑从 `route.params.category` / `route.params.slug` 改为从 `pathMatch` 数组拆分：

```
/blog/dream/钢琴
  → pathMatch = ["dream", "钢琴"]
  → slug = "钢琴", category = "dream"

/blog/Exploration and Reflection/首屏/前端3d技术讨论
  → pathMatch = ["Exploration and Reflection", "首屏", "前端3d技术讨论"]
  → slug = "前端3d技术讨论", category = "Exploration and Reflection/首屏"
```

刷新页面后，所有层级的文章均可正常访问。
