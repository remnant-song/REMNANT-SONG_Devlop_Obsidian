### 任务 8：国际化（i18n）核心集成

**描述**  
集成 `vue-i18n`（或轻量替代 `vue-i18n-next`），建立多语言切换机制，保证所有用户可见文本均通过语言文件管理。

**子项**

1. **安装依赖**
    - `vue-i18n@9` (与 Vue3 兼容)
2. **目录与文件结构**
    
```text
src/
├── i18n/
│   ├── index.ts          # 直接创建 i18n 实例并导出 (包含动态导入逻辑)
│   ├── locales/
│   │   ├── en.json
│   │   └── zh-CN.json
│   └── types.ts          # 可选，定义语言类型
```

3. **i18n 实例配置**
    - 默认语言：`'en'`（可根据浏览器语言 `navigator.language` 降级选择）
    - 回退语言：`'en'`
    - 持久化：将语言选择存入 `localStorage`，初始化时读取
        
4. **动态加载语言包工具**
    - `i18n/loadLocale.ts`：
        - 根据语言标识动态 `import(`../../locales/${locale}.json`)`
        - 利用 Vite 的 `?url` 或直接导入 JSON
        - 调用 `i18n.global.setLocaleMessage` 注入
5. **语言切换 UI 组件**
    - 创建 `components/LocaleSwitcher.vue`（与风格切换器类似，可暂放于 `BaseLayout` 中，开发阶段可见）
    - 支持 `en` / `zh-CN`（后续可扩展更多）
    - 切换时调用 `localeStore.setLocale`，并重新加载相关语言包（若未加载）
6. **开发体验**
    - 配置 Vite 别名 `@locales` 指向 `src/locales`，方便导入
    - 在 `tsconfig.json` 中支持 JSON 模块解析（默认已支持）
    - 提供 `scripts/auto-i18n.js`（可选）用于扫描未翻译的键，但不是必须

读取了 demo 文件和当前设置文件。现在来修改设置文件。

根据 demo 中的格式：`caps_<键名>=keyFunc_<功能>`，方向键功能对应：
- `keyFunc_moveUp` - 上
- `keyFunc_moveLeft` - 左
- `keyFunc_moveDown` - 下
- `keyFunc_moveRight` - 右

映射为：长按 CapsLock + **w**=上、**a**=左、**s**=下、**d**=右。

修改完成。最终 `CapsLock+settings.ini` 的 `[Keys]` 段内容如下：

```
[Keys]
; 长按CapsLock + w = 上
caps_w=keyFunc_moveUp

; 长按CapsLock + a = 左
caps_a=keyFunc_moveLeft

; 长按CapsLock + s = 下
caps_s=keyFunc_moveDown

; 长按CapsLock + d = 右
caps_d=keyFunc_moveRight
```

其余段（`[Global]`、`[QSearch]` 等）保持不变，未做改动。保存后重启 CapsLock+ 即可生效。
