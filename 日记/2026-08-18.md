## 改动总结

所有 5 个文件改动已预览完成。核心逻辑如下：

### 降级流程

```
页面加载
  ↓
loadAllPostsFromRemote()
  ↓
尝试 GitHub API（8 秒超时）
  ├── 成功 → 返回文章列表 ✅
  └── 失败（超时/网络错误/HTTP 错误）
        ↓
      自动降级到 Gitee 镜像 API
        ├── 成功 → 返回文章列表 ✅（用户无感）
        └── 失败 → 抛出错误 ❌
```

### 降级触发条件（确保判断准确）

| 场景 | 表现 | 是否降级 |
|------|------|---------|
| 大陆 DNS 污染/解析失败 | `fetch` 抛 `TypeError` | ✅ |
| TCP 连接超时 | 8 秒超时触发 | ✅ |
| 连接被 GFW 重置 | `fetch` 抛网络异常 | ✅ |
| GitHub API 返回 403/429 | HTTP 非 2xx | ✅ |
| GitHub API 返回 5xx | HTTP 非 2xx | ✅ |
| GitHub 正常响应 | 正常返回 | ❌ 不降级 |
