## 总结

两个 diff 一起修复了 Gitee CORS 问题：

| 改动 | 说明 |
|------|------|
| 端点切换 | `gitee.com/.../raw/...` → `gitee.com/api/v5/repos/.../contents/...` |
| 响应解析 | 纯文本 → base64 解码（`atob(data.content)`） |
| 路径编码 | 分段 `encodeURIComponent`，保留 `/` 分隔符 |

**为什么 Gitee raw 域名有 CORS 问题？** `raw.githubusercontent.com` 在响应头中带了 `Access-Control-Allow-Origin: *`，但 `gitee.com/.../raw/...` 没有。Gitee 的 API 端点（`gitee.com/api/v5`）则支持 CORS，所以改用它获取文件内容。
