这是一个典型的 SPA 客户端导航问题。让我先检查当前实际文件状态，定位根因。

## 根因分析

经过逐文件排查，定位到问题在 [DefaultLayout.vue](file:///d:/personal project/remnant-song-web/src/layouts/DefaultLayout.vue#L86-L89) 的 `<transition>` 组件。

**现象链：**
1. `<router-view v-slot="{ Component }">` 包裹 `<transition mode="out-in">`
2. 过渡 CSS 写在 `<style scoped>` 中 → `.page-fade-leave-active` 被编译为 `.page-fade-leave-active[data-v-xxxx]`
3. `mode="out-in"` 要求：**旧组件完全离开后，才挂载新组件**
4. 旧组件（HomeView）的根元素**没有** `data-v-xxxx` 属性 → CSS 选择器不命中 → 浏览器认为过渡时长为 0
5. 但 Vue 的 JS 过渡钩子仍在等 `transitionend` 事件 → 该事件可能不会按预期触发 → **新组件永远不被挂载**

**这就是为什么：**
- 刷新时正常：没有"旧组件离开"这一步，直接挂载 BlogListView
- 客户端导航时空白：旧组件离开的过渡"卡住"，新组件 BlogListView 永远不会被挂载，`<script setup>` 从不执行，控制台零输出

---

## 修复方案

去掉 `mode="out-in"`，保留过渡动画。

---

## 总结

**根因：** [DefaultLayout.vue:L87](file:///d:/personal project/remnant-song-web/src/layouts/DefaultLayout.vue#L87) 的 `<transition mode="out-in">` + `<style scoped>` 组合导致过渡钩子卡死，旧组件（HomeView）离开后新组件（BlogListView）永远不会被挂载。

**修复：** 去掉 `mode="out-in"`，保留 `name="page-fade"`。页面切换仍有淡入淡出效果，只是不再是"先出后进"的严格交错模式（改为同时进行）。

**副作用：** 无。过渡动画从"交错"变为"同时"，视觉效果几乎无差异（0.2s 的淡入淡出）。
